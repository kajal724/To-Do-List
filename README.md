# To-Do List Web Application

A simple and beginner-friendly To-Do List web application built using HTML, CSS, and JavaScript.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and clean user interface
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Use

1. Enter a task in the input box.
2. Click the *Add* button to add the task.
3. Click on a task to mark it as completed.
4. Click the *Delete* button to remove a task.

## Project Purpose

This project was created to practice basic HTML structure, CSS styling, JavaScript DOM manipulation, and event handling.
